# ETHEREAN 임시 구현 정책

## 회복 아이템 — 2026-11-05

협업 마스터 프롬프트2.3의 초기 정책을 적용한다. 사용자 최신 결정이 있으면 이 값을 대체한다.

- **지상에서만 사용 시작**, 회복 중 공중/벽 상태로 바뀌면 취소. 이동은 평상시35%로 허용하며 공격·점프는 불가하다.
- 초기 최대 소지량3개, 회복량20, 사용 시간1.2초. 모두 HealingItem.asset에서 변경할 임시 수치다.
- R키 또는 게임패드 방향키 위로 사용한다. 누르고 있기/회복 중 입력 예약으로 자동 연속 사용하지 않는다.
- 동시에 회복과 공격/점프를 새로 누르면 회복 시작을 우선한다. 이미 공격 중이면 회복을 시작하지 않는다.
- 정상 완료에서만 체력을 회복하고1개 소비한다. 유효 피격·사망·입력/이동/회복 컴포넌트 비활성·지상 이탈 시 취소하고 아이템을 보존한다. 무적으로 거부된 피해는 취소 원인이 아니다.
- 완료는 해당 프레임의 물리 피해 처리 후 수행하며, 같은 물리 시점의 유효 피격이 완료보다 우선한다. 종료 시 남아 있는 회복·공격·점프 요청도 비운다.
- 최대 수량이면 아이템은 남는다. 접촉 중 수량에 여유가 생기면 다시 획득을 시도한다.
- 적별 드롭 초기 확률: 오소리35%, 멧돼지50%. HealingDropData의 임시 수치이며 최종 밸런스가 아니다.
- 드롭 소멸 거리는16u. **거리 기준 이상 AND 카메라 화면 밖**일 때만 소멸한다. 고정 배치 아이템은 이 정리 대상이 아니다.
- 같은 플레이어의 사망/비활성화에서 수량과 누적 소비량을 초기화하지 않는다. 현재 프로젝트에 없는 새 플레이어 생성·체크포인트 복귀·게임 재실행 후 저장 복원은 다음 세이브 단위에서 연결한다. 이번 구현을 영구 저장 완료라고 표시하지 않는다.
- 아이템은 기존 사각형을 임시로 사용한다. 사용자 아트/VFX 슬롯은 별도 제작을 기다린다. 코드로 HUD·아이콘·회복 이펙트·애니메이션을 임의로 디자인하지 않는다.
