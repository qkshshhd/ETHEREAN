        1.2 게임 콘셉트
        검술에 익숙하지 않은 소녀가 가족과 고향을 잃은 뒤, 복수를 위해 검을 들고 낯선 세계를 탐
        험하는 2D 액션 메트로베니아 게임이다.
        플레이어는 다양한 지형과 적을 마주하면서 전투와 이동 기술을 익히고, 새로운 능력을 통해
        기존에 접근할 수 없었던 지역을 탐험한다.
        특히 주인공이 처음부터 뛰어난 검사가 아니라는 설정을 바탕으로, 게임 진행에 따른 검술과
        전투 능력의 성장을 주요 플레이 경험으로 제공한다.

        03. 플레이어 시스템 — 상태 관리 시스템
        3.7.1 설계 목표
        플레이어의 이동, 공격, 피격 및 전체 제어 상태를 관리한다.
        각 시스템의 책임을 분리하여 상태 간 충돌을 방지하고, 향후 대시, 패링, 새로운 검술 및 피
        격 반응을 추가할 때 기존 시스템의 변경을 최소화한다.


        3.7.2 상태 구분
        이동 상태 (Locomotion)
               Grounded: 지면에 있는 상태
               Airborne: 공중에서 이동하는 상태
               WallSlide: 벽을 따라 미끄러지는 상태
               WallCling: 벽에 매달린 상태
        Idle과 Run은 Grounded 상태에서 이동 입력과 수평 속도로 구분한다.
        Jump와 Fall은 Airborne 상태에서 수직 속도 및 이동 조건으로 구분한다.

        행동 상태 (Action)
               None: 별도의 전투 행동을 실행하지 않는 상태
               Attack: 검 공격을 실행하는 상태
        Attack은 내부적으로 Windup, Active, Recovery의 세 단계로 나뉜다.

               Dead: 사망하여 일반적인 행동을 실행할 수 없는 상태

        3.7.3 상태 전환 규칙
        이동과 공격
               지상과 일반 공중 상태에서는 공격을 사용할 수 있다.

               WallSlide와 WallCling 상태에서는 공격을 시작할 수 없다.
               벽에서 분리되어 일반 공중 상태가 되면 공중 공격을 사용할 수 있다.

               공격 준비 및 타격 중에는 일반 점프 캔슬을 허용하지 않는다.

               공격 회복 후반부부터 조건을 만족하면 점프 캔슬을 실행한다.

        이동과 피격
               경직 중에는 플레이어의 일반 이동 입력을 제한한다.

               넉다운 중에는 일반 이동 입력보다 넉백 동작을 우선한다.

               넉다운 후 기상 과정이 완료되면 이동 조작을 복구한다.

        공격과 피격
               일반 공격 중 피격되면 해당 공격을 중단한다.

               Stagger 반응에서는 짧은 경직 후 정상 행동으로 복귀한다.

        3.7.4 행동 제어
        PlayerStateCoordinator는 각 시스템의 상태를 확인하고 행동의 실행 가능 여부를 판단한
        다.

        이동, 공격, 피격 시스템은 각자의 행동 실행과 상태 변경을 담당한다.
        공격으로 발생하는 이동 제한과 피격에 의한 넉백은 서로 충돌하지 않도록 일관된 이동 제어
        과정을 거쳐 적용한다.


        3.7.5 능력 해금 관리
        능력 획득 여부와 현재 실행 상태를 구분하여 관리한다.

               검을 획득하기 전에는 공격을 사용할 수 없다.
