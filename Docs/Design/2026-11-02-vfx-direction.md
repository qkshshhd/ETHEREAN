# ETHEREAN VFX 방향 — 2026-11-02
> 2026-11-03 기준점 변경: 독립 대검 프리팹을 제거했다. 준비/타격 VFX는 캐릭터의 AttackEffectOrigin, 명중 VFX는 실제 접점을 기준으로 한다. 기존 프리팹 슬롯과 None 기본 정책은 유지한다. 검과 몸체는 향후 캐릭터 애니메이션 안에 함께 표현하며 실제 리소스는 아직 미연결이다.
> 최신 사용자 결정: 전투 효과는 사용자가 커스텀할 프리팹을 연결하는 구조로 한다. 코드로 그리던 궤적·명중 섬광·색상 변경은 폐기했다. 준비/타격/명중 프리팹 슬롯은 기본 None이며, 슬롯을 채우기 전 효과가 없는 것이 정상이다. 앞선 방향 동의가 코드로 VFX 모양을 만드는 승인이라는 뜻은 아니다. 최신 연결은 PlayerAttackData의 Windup/Swing/Hit Effect Prefab과 PlayerAttackEffects를 따른다. 실제 사용자 VFX 제작은 아직 완료하지 않았다.

## 1. 목표와 승인 상태

사용자는 자연스러운 먼지, 절제된 은회색 검 궤적, 명중 순간의 강한 반응이라는 방향에 동의했다. 이동은 가볍고 자연스럽게, 대검 타격은 짧고 묵직하게 표현한다. 방향 결정과 기록은 완료했으며 에셋 제작·코드 연결·실제 화면 검증은 미착수다. 주인공 실제 아트 디자인 승인을 포함하지 않는다.

## 2. 대상별 표현 기준

| 대상 | 승인된 방향 | 구현 시 확인점 |
| --- | --- | --- |
| 달리기·방향 전환 | 작은 발밑 흙먼지, 급제동 시 강조 | 일정한 이동마다 과도하게 분사하지 않고 발판 끝을 가리지 않음 |
| 점프·착지 | 도약의 작은 먼지, 착지 충격에 따른 옆 방향 확산 | 바닥 점프/착지 판정과 일치, 공중에서 지면 먼지 발생 방지 |
| 벽 미끄러짐·벽차기 | 접촉점의 흙·돌가루와 도약 순간 파편 | 유효한 벽 접촉과 연동, 벽 매달리기는 제외 |
| 대검 공격 | 짧고 두꺼운 은회색 궤적, 끝은 빠르게 흩어짐 | 타격 단계와 실제 검 동작에 맞춤, 공격 중단 시 남는 궤적 관리 |
| 명중 | 접점의 밝은 섬광과 짧은 파편 | 실제 적중 시 발생, 허공 공격과 구분, 슈퍼아머 적중에도 표시 |
| 플레이어 피격 | 짧은 몸체 밝기 변화와 충격 방향 표시 | 실제 유효 피해와 일치, 공격 명중 표현과 구분 |
| 적 공격 준비 | 자세 변화와 작은 경고 표시 | 위험 시점·방향이 읽히며 색상만으로 구분하지 않음 |
| 회복 | 몸 가까이 모였다 사라지는 부드러운 빛 | 진행과 완료 구분, 취소되면 완료 효과 없음 |

## 3. 팔레트와 형태

먼지·파편은 저채도 흙색/회색의 작은 픽셀 덩어리를 기본으로 한다. 검 궤적·타격은 은회색/밝은 아이보리 계열이며 밝은 부분을 짧게 사용한다. 위험 예고의 탁한 주황색과 회복의 옅은 녹색은 실제 숲 배경에서 비교할 색상 후보다. 정확한 RGB/HEX와 밝기·크기·프레임 수·지속 시간·방출량은 아직 확정하지 않았다. 캐릭터40px는 임시값이며 효과 크기를 그 값에 영구 고정하지 않는다.

## 4. 설정과 가독성

숲 B의 차갑고 쓸쓸한 기조를 유지한다. 초반 소녀는 개안하지 않았으므로 일반 이동과 기본 검 공격에 보라색 오라·마법진·에너지 폭발을 사용하지 않는다. 벽 이동 능력은 동작과 마찰로 표현한다. 학습을 새로운 마법 아이템 획득으로 연출하지 않는다. 배경 균열은 기존의 작고 강조 없는 배경 규칙을 유지한다.

효과가 발판 끝·적 준비 자세·공격 방향을 가리지 않게 한다. 공격의 묵직함을 이유로 기존 일반 이동을 느리게 바꾸지 않는다. 체크포인트·아이템·전환 등 여기서 구체화하지 않은 효과는 기존 제작 목록의 요구로 남으며 새 외형을 확정하지 않는다.

## 5. 명중 피드백과 향후 실행 흐름

짧은 히트스톱과 약한 화면 흔들림을 명중 피드백 후보로 함께 조율한다. 이들은 렌더 효과와 별개인 시간/카메라 처리이며 정확한 강도·시간·적용 대상은 구현 전에 정한다. 일반 이동에는 적용하지 않는 방향이다.

향후 흐름은 이동·착지·벽 접촉 또는 공격/적중 결과 확정 → 해당 표현 요청 → 표현 재생·종료다. VFX가 피해 판정이나 Rigidbody2D 이동을 결정하지 않는다. 공격 궤적과 적중 효과는 각각 공격 단계와 적중 결과에 연결한다. 이는 설계 기준이며 해당 클래스·이벤트는 이번에 구현하지 않았다. 실제 코드 연결점은 전투 묶음 설계에서 정한다.

## 6. 제작 순서와 직접 확인

다음 전투 묶음에서 검 궤적·명중 섬광부터 실제 공격 판정에 맞춰 검토하고 이동 먼지·피격·경고·회복은 해당 기능에 연결할 때 제작한다. 모든 효과를 이번에 일괄 제작한 것으로 취급하지 않는다.

직접 확인은 이 문서 2절과 제작 목록의 VFX 구역을 읽어 방향을 검토하는 단계다. Unity에서 효과를 볼 씬·프리팹·Inspector 연결은 아직 없다. 구현 후에는 허공/적중/슈퍼아머/공격 취소, 회복 성공/취소, 이동·벽 이탈 상황에서 가독성과 잔류 효과를 확인해야 한다.

## 7. 검증과 제한

실행한 확인: Git 상태, 기존 리소스 목록과 GDD의 공격 동작·판정 일치 및 슈퍼아머 적중 표현 규칙 확인, 문서 연결·저장 내용 확인. Unity 컴파일·Play Mode·렌더 검사는 이번 문서 작업에서 실행하지 않았다. 이전 이동 검사를 VFX 검증으로 사용하지 않는다. 제작 속도·성능·실제 가독성은 미측정이다.
