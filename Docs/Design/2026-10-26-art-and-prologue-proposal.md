# ETHEREAN 아트 규격과 프롤로그 제작 검토안
> 최신 기준(2026-10-28): 주인공은 귀여운 2등신으로 선택. 표시 높이는 우선 40px지만 확정값이 아니며 언제든 바뀔 수 있다. 아래 2~3등신 범위와 크기 미정 설명은 이전 검토 이력이다. 구체 외형은 미정이며, 현재 기준은 2026-10-27-pixel-scale-review.md를 따른다. Unity 가이드·충돌체의 크기는 이번 문서 기록으로 변경되지 않았다.

작성: 2026-10-26. 상태: 사용자 선택 전 검토안. 기준 문서: 협업 마스터 프롬프트, GDD 02 및 05파트, 일일 개발 계획. 사용자 결정: 벽 매달리기 제외, 주인공은 귀여운 2~3등신 데포르메, 숲은 B의 차갑고 쓸쓸하며 더 이상 행복하지 않은 분위기. 화면 규격, 구체 색상값과 연출 시간은 제안이다. 이미지 속 소녀 외형은 채택하지 않으며 주인공 외형 정보로 저장하지 않는다.

## 1. 제안의 목표와 확인한 현재 값

현재 조작감과 화면에서 보이는 캐릭터 비율을 크게 바꾸지 않으면서, 11월 8일까지 제작 가능한 일관된 픽셀 아트 규격을 정한다. 이야기의 핵심은 평범한 소녀가 무거운 부모의 대검을 들고 낯선 자연 속으로 들어가는 대비다. 이동은 경쾌하게, 공격은 무겁게 표현한다.

실제 파일 확인: MovementSquare.png.meta는 32 PPU, Player.prefab의 충돌체는 0.8×1.8u, 루트 Scale은 1, PlayerMovementTest.unity 카메라 Orthographic Size는 5.5다. 이 문서를 작성하며 해당 값을 변경하지 않았다.

분위기 비교 이미지에서는 B 숲의 정서를 선택했다. 이미지 속 소녀는 디자인 참조에서 제외한다. 해당 이미지는 정밀한 640×360 게임 화면이나 32 PPU 스프라이트가 아니며 인물의 외형과 화면 점유율을 제작 기준으로 사용하지 않는다.

## 2. 픽셀 밀도와 기준 화면 제안

| 항목 | 추천 검토값 | 의미와 주의점 |
| --- | --- | --- |
| 기준 게임 화면 | 640×360, 16:9 | 게임 세계를 그릴 기준 해상도. 창 크기나 모니터 해상도와 구분 |
| 기본 출력 | 1280×720 및 1920×1080 | 기준 화면의 정수 2배와 3배. 다른 화면 비율의 대응은 별도 검증 |
| 월드 아트 PPU | 32 | 32픽셀이 1유닛. 현재 테스트 스프라이트와 동일한 기준 |

| 픽셀 표현 | Point, 압축과 픽셀 카메라 설정 검토 | 카메라 움직임과 서브픽셀 흔들림은 실제 Unity 화면에서 확인해야 함 |

추천 이유: 640×360과 32 PPU는 현재 약 1.8u 캐릭터가 화면 높이의 약 1/6을 차지하는 비율을 유지하면서 얼굴, 대검과 피격 동작을 표현할 공간을 확보한다. 더 낮은 해상도로 제작량을 줄일 수 있지만 같은 시야에서 얼굴과 칼 동작의 세부 표현이 줄어든다. 높은 해상도는 그림과 프레임 수정량이 늘어난다. 수치만으로 최종 가독성을 검증했다고 판단하지 않는다.

발바닥 위치와 피벗을 동작 간 공통 기준으로 정한다. 검을 얻기 전 몸체와 검 획득 후 몸체는 가능하면 공통 이동 그림을 재사용하되, 검의 무게를 보여 주는 별도 포즈가 필요한 부분을 구분한다. 시각 Scale로 캐릭터를 늘려 충돌체까지 바꾸지 않는다.

## 3. 확정한 숲 분위기와 색상 검토

사용자가 선택한 방향은 **B 숲**이다. 숲은 더 이상 행복하지 않은 곳처럼 느껴져야 한다. 차가운 청록색과 회청색, 낮은 채도, 약한 빛과 옅은 안개로 상실감과 쓸쓸함을 표현하는 방향을 제안한다. 이는 정서적 아트 방향이며 숲에 저주나 생태계 붕괴가 생겼다는 새 설정을 확정한 것은 아니다. 구역의 안전함은 강한 따뜻한 색 전환 대신 시야와 여유 공간, 적 배치 등으로도 전달한다. 구체 팔레트와 연출은 별도 검토한다.

| 구역 | 분위기와 역할 | 표현 방향 |
| --- | --- | --- |
| 프롤로그 마을 | 일상과 안전 | 크림, 흙색과 낮은 채도의 따뜻한 햇빛 |
| 산길 | 평범한 산행 | 자연스러운 암석과 바람. 작은 배경 균열은 인지·발견 연출 없이 배치 |
| A와 B 및 C 초입 | 행복이 사라진 숲의 첫인상 | 차가운 청록과 회청색, 낮은 채도, 약한 빛과 옅은 안개 |
| C 하부와 D | 경계와 위험 | 차가운 청록 음영, 굵은 뿌리와 지층. 공격 예고는 배경에서 분리 |
| E | 쓸쓸한 숲 안의 안전한 공간 | 차가운 기조는 유지하고 열린 시야와 여유 공간으로 휴식을 구분 |

| H와 I | 시야가 열리는 변화 | 익숙한 지형과 열린 원경. 숲 안의 차갑고 쓸쓸한 기조는 유지 |

주인공 외형에서 저장할 결정은 **귀여운 2~3등신 데포르메**뿐이다. 정확한 등신, 얼굴, 몸체 실루엣, 머리색과 머리 모양, 의상, 소품과 캐릭터 팔레트는 모두 미정이다. 생성 이미지의 소녀는 향후 디자인 참조나 제작 원본으로 사용하지 않는다. 대검의 서사 및 무게감 표현은 기존 기획 요구로 유지하며 예시 이미지의 검 모양을 채택한 것은 아니다.

위 색상은 환경 팔레트 검토용 예시이며 확정 색상표가 아니다. 주인공의 색상 제안은 제거했다. 초반 주인공에게 개안이나 우주적 힘을 표현하지 않는 기존 설정은 유지한다.

화면 계층은 충돌 지형과 플레이 대상이 가장 읽히게 하고, 중경과 원경은 대비와 세부 밀도를 낮춘다. 풀과 먼지가 발판 끝, 적의 예고와 공격 범위를 가리지 않도록 한다. 이동 가능한 면은 색 하나에만 의존하지 않고 윤곽과 높낮이로도 구분한다.

UI는 짙은 반투명 바탕과 얇은 테두리를 기본 후보로 한다. 왼쪽 위 체력과 회복 수량, 대상 근처 상호작용 표시, 아래쪽 짧은 대화 영역을 우선 배치한다. 한글은 작은 픽셀 글꼴 형태보다 실제 출력에서 읽히는지 먼저 확인한다.

## 4. 프롤로그 콘티

2026-10-27 최신 결정: 균열 접근·발견과 물건 낙하 장면을 제거한다. 평범한 산행과 귀환 후 집에서 무언가 두고 왔음을 알아차리고 재앙이 시작된다. 작은 균열은 강조 없는 배경 흔적만 남긴다. 플레이어가 재앙의 원인과 검객의 정당성을 먼저 알게 하는 장면은 사용하지 않는다. 이전 10컷 이미지보다 최신 텍스트 콘티를 따른다.

상세 제작 기준은 [프롤로그 장면 순서와 콘티](2026-10-26-prologue-storyboard.md)에 분리했다. P01~P09의 목적, 구도, 조작, 정상 완료와 스킵 결과, 필요한 리소스 ID와 확인 조건을 그 문서에서 관리한다. 기준 시간 제안은 합계 275초이며 최초 플레이 4~6분 목표는 아직 실측 전이다. 대검 획득 장소와 검객 행동의 공개 범위는 검토 대기다.

## 5. 제작 목록

상세 제작 목록은 [리소스 제작 목록](../Plans/ETHEREAN_Asset_Production_List.md)에서 관리한다. 활성 항목은 캐릭터 15, 적 8, 환경 19, UI 11, VFX 13의 총 66개 작업 묶음이며 이전 4개는 제외 이력으로 보존한다. 실제 파일이나 프레임 수를 뜻하지 않는다. 각 행에서 사용 구간, 우선순위, 목표일, 재사용과 상태를 확인한다. 구체 외형, 프레임 수와 픽셀 규격은 확정하지 않았다.

## 6. 먼저 확인할 실제 제작 샘플

1. 소녀의 앞과 옆 실루엣, 대검을 든 정지 포즈를 만든다. 이미지의 정확한 크기와 발 기준을 확인한다.
2. 640×360 기준의 작은 숲 샘플에서 캐릭터와 32px 지형, 발판 끝이 잘 구분되는지 본다.
3. 실제 출력 1280×720과 1920×1080에서 확대 비율, 얼굴, 한글, 카메라 이동 시 흔들림을 확인한다.
4. 짧은 공격 궤적, 적 예고와 타격 표현 하나씩을 붙여 같은 화면에서 읽히는지 본다.
5. 9개 장면의 러프 콘티를 확인한 뒤 필요한 NPC 포즈와 소품만 최종 목록으로 남긴다.

이 샘플 구현과 프로젝트 설정 적용은 사용자 선택 후 별도 작업이다. 오늘 문서 작업에서 플레이어와 카메라 및 입력을 수정하지 않았다.

## 7. 사용자가 선택할 항목과 현재 작업 결과

- 규격 후보: 640×360, 32 PPU, 64×64 프레임. 캐릭터 몸체 픽셀 크기는 미정이며 실제 외형 검토 후 정한다.
- 확정 분위기: B 숲. 차갑고 쓸쓸하며 더 이상 행복하지 않은 숲의 정서. 구체 팔레트와 빛의 강도는 미정.
- 주인공 외형의 저장 범위: 귀여운 2~3등신 데포르메만 확정. 생성 이미지의 소녀 외형과 소품은 채택하지 않는다.
- 프롤로그 9장면과 4~6분 목표 및 배경 3세트 재사용 방향.

완료: 현재 저장된 프로젝트 규격 확인, 추천 수치의 산술 관계 확인, 분위기 비교 콘셉트와 콘티 및 제작 목록 초안 작성. 부분 확정: 주인공은 귀여운 2~3등신, 숲은 B의 차갑고 쓸쓸한 정서. 미완료: 정확한 비율, 새로운 세부 외형, 구체 팔레트와 화면 규격의 사용자 선택. 미검증: 실제 픽셀 스프라이트의 품질, 애니메이션, 실제 Unity 출력과 카메라 샘플, 프롤로그 시간 및 진행. 측정한 성능 수치는 없다.

초안 작성 때 추가한 프로젝트 파일은 이 문서 하나다. 1절은 현황과 전제, 2~3절은 화면과 아트 규격, 4절은 프롤로그 콘티, 5절은 제작 범위, 6~7절은 확인 순서와 결정 항목을 담당한다. 기존 프로젝트 파일은 수정하지 않았다. 사용자 선택 후 규격을 확정하고 일일 계획의 완료 기록을 갱신한다.

## 변경 기록

- 2026-10-26 사용자 피드백 반영: 주인공은 귀여운 2~3등신으로 기록.
- 2026-10-26 최신 결정: 숲은 B의 차갑고 쓸쓸하며 더 이상 행복하지 않은 분위기로 선택. 예시 소녀의 외형과 색상 제안을 제거하고 주인공은 등신 범위만 저장. 이전 A 기본 추천과 인물 시안의 세부 묘사는 현재 기준에서 철회.

- 2026-10-27: 프롤로그 정보 공개 방식 변경 반영. 9장면과 활성 리소스 66묶음 기준으로 안내 수정. 산의 균열을 발견 이벤트에서 작은 배경 요소로 변경했다.
