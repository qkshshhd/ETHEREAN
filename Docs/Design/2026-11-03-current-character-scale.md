# 현재 캐릭터 크기 기준

사용자 결정: 2026-11-03. 현재 작게 보이는 캐릭터에 맞춰 점프·중력과 관련 플레이 수치를 조정하고, 앞으로 작업할 때도 현재 캐릭터 크기를 기준으로 개발한다.

## 기준과 우선순위

- 현재 공급된 Idle/Walk/Run 원본: 32×32 PNG, 32 PPU, CharacterVisual 스케일 1.
- 설계 계산에 사용할 대표 가시 높이: **30px = 0.9375u**. 프레임별 실제 가시 높이는 약 28~31px으로 달라진다. 투명 캔버스 높이 32px과 구별한다.
- 과거의 40px 제안과 1.8u 사각형보다 **현재 실제 캐릭터 크기**를 우선해 플레이를 맞춘다. 그림 자체를 확대하거나 PPU를 바꿔 맞추지 않는다. 이는 최종 아트 크기를 영구 확정하는 결정은 아니다.
- 과거 비교 씬의 60px 도형은 역사적 비교 자료다. 신규 개발의 물리 기준으로 사용하지 않는다.

## 앞으로의 개발 원칙

1. 이동·점프·공격 사거리·피격 및 넉백·적 크기·지형 높이·통과 폭·아이템·월드 VFX는 현재 캐릭터 높이와 상대 크기를 먼저 확인한다.
2. 신규 테스트 씬도 현재 크기로 구성한다. 기존 1.8u 사각형 기준의 장애물을 그대로 신규 기준으로 복사하지 않는다.
3. 현재 Player 프리팹과 실제 저장된 Inspector 값이 실행 기준이다. 스크립트 기본값만 바꾸고 프리팹 값이 적용됐다고 판단하지 않는다.
4. 가시 크기, 물리 콜라이더, 공격 판정은 각각의 목적에 맞춰 조율한다. 머리카락·망토의 모든 픽셀을 몸 충돌체로 취급하지 않는다.
5. 시간 값과 공간 값을 구별한다. 단순 크기 변경을 이유로 코요테/버퍼·공격 준비/타격/후딜·콤보 재정비 시간을 자동으로 줄이지 않는다.
6. 리소스 크기가 나중에 달라져도 런타임에서 자동으로 전체 수치를 바꾸지 않는다. 새 기준을 측정하고 사용자의 변경 요청 범위에서 프리팹·판정·레벨을 함께 검토한다.
7. 화면 공간 UI는 캐릭터 배율로 일괄 축소하지 않는다. 32 PPU 픽셀 설정과 화면/카메라 설계는 별개다.

## 이번 초기 조정

기존 기준 1.8u → 0.9375u. 비율 `s = 0.9375 / 1.8 = 0.5208333`.

길이, 속도, 가속도, 중력을 모두 s배하면 거리/캐릭터 높이, 가속 시간, 체공 시간을 유지할 수 있다. 연속식에서 `최고점 = v²/(2g)`는 s배, `최고점 시간 = v/g`는 동일하다. 실제 결과는 FixedUpdate 간격과 충돌 처리로 조금 달라지므로 측정한다.

| 항목 | 이전 | 새 초기값 |
| --- | ---: | ---: |
| 충돌체 폭×높이(u) | 0.8×1.8 | 0.416667×0.9375 |
| 이동 속도(u/s) | 6 | 3.125 |
| 가속도(u/s²) | 40 | 20.833334 |
| 감속도(u/s²) | 60 | 31.25 |
| 점프 속도(u/s) | 16 | 8.333334 |
| 상승 중력(u/s²) | 42 | 21.875 |
| 하강 중력(u/s²) | 48 | 25 |
| 최대 낙하 속도(u/s) | 20 | 10.416667 |
| 벽차기 수평/수직 속도(u/s) | 8 / 16 | 4.166667 / 8.333334 |
| 벽 미끄러짐 제한(u/s) | 3 | 1.5625 |
| 바닥·벽 감지 거리(u) | 0.05 | 0.026041667 |
| Idle/Run 전환 속도(u/s) | 0.1 / 3 | 0.052083334 / 1.5625 |

지상/공중 3타 판정의 offset/size와 knockback도 같은 비율로 맞춘다. 공격 피해·각도·시간·입력 정책, 점프 컷 0.5, 지상/벽 코요테 0.1s, 버퍼 0.1s, 벽차기 제어 보호 0.1s는 유지한다. 새 수치는 초기 튜닝값이며 사용자가 조작감을 검토한다.

기존 테스트 씬의 저장된 위치·override는 보존한다. 특히 PlayerMovementTest의 wallJumpHorizontalSpeed=4는 과거 명시 override이므로 현재 크기에서 검사할 때는 새 PlayerCurrentScaleTest를 사용한다. 새 씬은 기존 전투 테스트의 지형·벽·대상 크기와 배치를 s배로 맞추며 카메라 orthographicSize/PPU는 유지한다.

실행 결과와 실제 변경 파일 목록은 `Docs/Reports/2026-11-03-current-character-scale.md`에 기록한다.

## 2026-11-03 최신 상태 보정

실제 일괄 크기 변환은 사용자 수정 콜라이더를 감지한 안전 가드에서 중단되었다. 위 비례 조정 표를 적용 완료 값으로 해석하지 않는다. 현재 충돌체는 size=(0.4948379,0.88451296), offset=(-0.003912464,-0.4577435)이며 보존한다. 후속 사용자 피드백에 따라 점프 10, 상승 중력 40, 하강 중력 65, 낙하 상한 16, 벽차기 수직 10으로 조정하는 별도 단위를 진행한다. 실제 적용/검증 상태는 Docs/Reports/2026-11-03-weighted-jump-and-test-map.md가 우선한다. 현재 캐릭터 크기를 기준으로 앞으로 개발한다는 원칙은 유지한다.
