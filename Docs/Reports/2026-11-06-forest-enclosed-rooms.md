# 첫 번째 숲: 통로 지형과 방별 화면

기존 A → B → C → D → E → F → G → H → B → I 순서를 유지하고, 이동하는 통로가 하나의 공간으로 보이도록 바닥·천장과 카메라를 함께 개편했다. A~H의 일반 통로는 지면 아래와 천장 위를 기존 0.5u 타일로 채웠다. 하강, 지름길, H→B 낙하처럼 이동에 필요한 개구부는 남겼고, I의 바깥 능선 위는 열어 뒀다.

| 구간 | 변경 내용 |
| --- | --- |
| A / B | A의 빈 진입부를 압축해 벤치 다음에 넓은 오르막 하나와 낮은 봉우리를 둔다. B는 한 번 길게 내려갔다 올라오는 본길을 유지한다. 기존 샛길 위에는 머리 공간을 남기고, H 복귀와 I 진입에 필요한 부분만 천장을 열었다. |
| BC / C | 뿌리 하강로는 짧은 낙차 사이에 타일 경사 세 곳을 둔다. C는 입구 관찰 언덕 뒤에 넓은 전투 바닥과 높아지는 동쪽 출구가 있다. 지름길 갱도는 별도 방처럼 카메라가 따라간다. |
| D / E | 전투장 폭 17u는 유지하고, 그 앞의 빈 접근로와 동쪽 회차부를 안으로 옮겼다. D 하강 후 E 바닥에서는 방향을 바꿀 공간을 확보했다. E 쉼터 근처는 평평하고, 돌아오는 길에는 긴 완만한 언덕 한 곳만 남겼다. |
| F / G | F의 반복 언덕을 낮은 턱 하나와 두 단계로 이어지는 긴 언덕으로 교체했다. G의 입구와 연습 벽을 동쪽으로 옮겼다. 기존 세 암벽 구간과 쉼턱, 안전 바닥은 유지하고, 천장과 바깥 암벽을 두껍게 채웠다. |
| H / I | H를 여러 개의 같은 봉우리 대신 길게 이어지는 비대칭 능선으로 만들었다. 끝에서 B로 떨어지는 폭 4u의 개구부를 남겼다. I 암벽 아래는 B에서 보이도록 하고, 암벽을 벗어난 능선은 천장을 두지 않았다. |

기존 하층 동쪽 끝과 G 입구의 가로 거리 합계가 약 20u 줄었다. 이는 좌표 비교이며 플레이 시간 실측이 아니다. C↔E와 H→B 지름길의 진입 및 개방 방식은 그대로다.

| 파일 | 위치와 동작 |
| --- | --- |
| `Assets/_Project/Scenes/ForestWhitebox.unity` | 각 `Editable Terrain Grid > Terrain Source - Paint Here`의 바닥·천장·경사 타일과 통합 충돌 외곽선을 교체했다. `CE - Shortcut Shaft` 및 `BI - Exit Threshold`로 연결부를 분리했다. `Forest Whitebox Camera > Rooms`에 `Visible Roots`와 새 구간 범위를 연결하고, D의 멧돼지·게이트·진행 범위와 A/E 벤치, 일부 픽업을 새 바닥에 맞췄다. |
| `Assets/_Project/Scripts/Runtime/World/ForestWhiteboxCamera.cs` | `FindRoom`이 현재 방을 고르고, 다음 방의 범위에 들어가기 전에는 기존 방을 유지한다. `ForestRoomVisibility`는 방이 바뀔 때 그 방에 등록된 렌더러만 그리도록 설정한다. 몬스터가 리스폰되면 새 인스턴스의 렌더러에도 같은 규칙을 적용한다. 실내는 어두운 임시 배경을 쓰고, `I - Exit Ridge`만 기존 하늘색 배경을 쓴다. 기존 충돌, AI, 세이브 동작을 끄지 않으며, 카메라를 끄면 이전 렌더링 상태를 복원한다. |
| `Docs/Reports/2026-11-06-forest-enclosed-rooms.md` | 새 작업 기록. 이전 개편의 단면도는 이번 카메라·지형 개편을 반영하지 않는다. |

## Unity에서 확인할 순서

1. `ForestWhitebox`를 16:9로 Play한다. A, B, C, E에서 Game 뷰에 위·아래층의 다른 방이나 몬스터가 비치지 않는지 확인한다. Scene 뷰는 전체 지형 편집에 사용하며, Play 중에는 카메라가 적용한 렌더링 상태도 반영된다.
2. D를 지나 E로 떨어진 뒤 바로 왼쪽으로 돌아선다. 지면과 천장 사이에 끼이지 않는지 확인한다. E에서 C 지름길을 열고 양방향으로 통과한다.
3. F에서 벽차기를 얻고 G의 두 쉼턱에서 각각 착지한다. H에서 B로 떨어져 I로 오른다. H→B가 두꺼워진 천장에 걸리지 않고, I 능선에서 화면 위가 열리는지 확인한다.
4. 체크포인트에서 앉아 몬스터를 리스폰한 뒤, 다른 방에 있는 몬스터가 비치지 않는지 확인한다. 새 진행 상태가 필요하면 기존 저장을 지우지 않고 별도의 임시 Editor 저장 파일명을 사용한다.

저장된 씬의 방 판정 좌표 17곳, 중첩되지 않는 렌더링 참조, 층별 바닥·천장 높이, D→E 회차와 C↔E·G·H→B 개구부를 정적으로 확인했다. Unity 6.4.7f1 프로젝트 참조 기반 런타임·편집기 C# 컴파일은 통과했다. Unity 배치 실행이 초기화에서 종료되어 실제 Game 뷰와 연속 플레이는 확인하지 못했다.
