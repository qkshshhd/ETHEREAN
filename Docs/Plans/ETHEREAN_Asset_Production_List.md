# ETHEREAN 리소스 제작 목록

작성: 2026-10-26. 최신 수정: 2026-10-27. 상태: 제작용 검토 초안. 범위: 프롤로그부터 첫 숲 탈출까지. 장면 배치와 외형은 사용자 최종 검토 전이다.

## 1. 사용 기준

- 주인공 외형의 확정 사항은 귀여운 2~3등신뿐이다. 생성된 예시 소녀의 머리, 얼굴, 옷, 색상, 소품과 검 모양을 사용하지 않는다.
- 숲은 B의 차갑고 쓸쓸하며 더 이상 행복하지 않은 정서를 따른다. 정확한 색상표, 픽셀 크기와 프레임 수는 미정이다.
- 벽 매달리기와 전용 리소스는 제외한다. 적은 오소리와 멧돼지 두 종이며 나이트메어는 프롤로그 연출 후보로만 다룬다.
- 현재 활성 제작 항목은 66개 작업 묶음이다. 초기 70개 중 정보 공개 원칙으로 제외한 4개는 문서 끝의 이력으로 분리했다. PNG 파일 수, 애니메이션 프레임 수나 이미 제작한 수량을 뜻하지 않는다. 같은 원화를 여러 상태에서 재사용할 수 있다.
- P0: 해당 기능의 첫 검증에 필요한 표현. P1: 전체 플레이 연결 전 필요한 표현. 조건부: 정보 공개와 콘티 결정 후 필요할 때만 제작.
- 각 행의 체크박스는 최종 확인 완료를 뜻한다. 상태는 현재 모두 요구 정리다. 원화 또는 소스 준비, Unity 연결, 실제 동작 확인 및 사용자 리뷰 후 체크한다.
- 목표일은 기존 일정과 연결한 제안이다. 코드 기능이 완료됐다는 뜻이나 새 기능 실행 승인이 아니다.
- 프로젝트에서 확인한 시각 원본은 현재 MovementSquare.png 임시 이미지다. 이 목록의 완성 원화와 애니메이션이 준비돼 있다고 가정하지 않는다.

관련 문서: [프롤로그 콘티](../Design/2026-10-26-prologue-storyboard.md), [아트 규격과 결정](../Design/2026-10-26-art-and-prologue-proposal.md), [일일 계획](ETHEREAN_Daily_Plan_2026-11-08.md).

## 8. 제작 순서와 재사용

1. CHR-01로 새로운 소녀 외형을 검토한다. 사용자 선택 전 다른 소녀 이미지나 미정 픽셀 규격을 확정 원화로 취급하지 않는다.
2. CHR-02·CHR-03과 ENV-09·ENV-11의 작은 샘플을 한 화면에 놓고 크기, 발 위치, 발판과 배경 가독성을 확인한다.
3. CHR-05와 FX-03·FX-04를 만들어 대검의 준비, 타격과 회복이 읽히는지 먼저 본다. 그림 수와 공격 시간은 별개로 조정한다.
4. ENM-01~04, ENM-05~08 순서로 적을 붙인다. 몸체 접촉과 공격 Active, 슈퍼아머 피해와 기절을 실제로 구분한다.
5. 집과 마을은 사건 전후에 같은 기본 배경을 쓰고 ENV-03과 음향으로 차이를 만든다. 산길 귀환도 같은 세트를 사용한다.
6. UI-01·UI-02·UI-03·UI-04·UI-11은 공통 패널과 입력 표시 소스를 공유한다. 각 역할과 표시 조건은 구분한다.
7. 먼지와 타격 입자는 공통 소스를 재사용하되 바닥 재질, 방향과 강도만 바꾸는 방안을 검토한다. 배경과 공격 예고를 가리지 않게 한다.

## 9. 완료 판정과 납품 기록

- 원본: 수정 가능한 소스와 내보낸 결과물의 위치를 기록한다. 외부 리소스라면 출처와 사용 조건도 기록한다.
- 시각 규격: 승인한 PPU와 프레임 크기, 발 기준, 피벗, 배경과의 대비를 확인한다. 아직 미정인 규격을 임의 확정하지 않는다.
- 연결: 해당 기능의 장면, 프리팹 또는 UI에서 참조를 확인한다. 외형으로 실제 공격 판정과 충돌체 크기를 자동 결정하지 않는다.
- 동작: 시작, 정상 종료, 취소, 피격과 사망, 재활성화와 연출 스킵 뒤 잔류를 확인한다.
- VFX: 상태 결과를 표시하고 피해와 진행 상태 자체를 결정하지 않는다. 캐릭터와 바닥 및 적의 예고를 가리지 않는다.
- 리뷰: 실제 확인한 장면과 로그 또는 영상을 남기고 사용자 확인 후 체크한다.

## 10. 사운드 연결 메모와 후순위

콘티에는 부모의 짧은 대화, 문, 발소리, 산 바람, 마을 소란과 이후 정적, 검의 무게감 및 숲 환경음을 연결점으로 적었다. 곡, 음원 수량과 구체 대사는 아직 미정이다. 같은 위치의 전후 음향 차이를 우선 활용한다.

추가 초상화, 주민별 고유 애니메이션, 배경의 많은 변형과 정교한 화면 효과는 핵심 진행을 연결한 뒤 검토한다. 원본 GDD에 없는 새 적과 보스, 새 장비 및 매달리기 리소스를 이 목록 때문에 추가하지 않는다.
