# ETHEREAN 일일 개발 실행 계획

기간: 2026-10-26 ~ 2026-11-08 | 작성 기준: 2026-10-26 | 최종 리뷰: 박준우

## 목표와 사용법

목표는 2026년 11월 8일까지 프롤로그부터 첫 번째 숲 탈출까지 아트, UI와 VFX가 적용된 짧은 Windows 플레이 버전을 만드는 것이다.

하루 8~12시간 수준의 집중 작업을 가정한 도전 일정이다. 사용 가능 시간과 리소스 준비 상태는 아직 확정되지 않았으며, 첫 이틀의 실제 작업량으로 목표를 재조정한다. 시간은 구현, 시각 작업, 검토, 테스트와 수정을 합친 추정치다.

한 날짜의 여러 작업은 순서가 있는 목표다. 기능 하나를 승인받아 구현하고 검증, 코드 설명과 사용자 리뷰를 끝낸 뒤 다음 단위로 진행한다. 이 문서는 미래 기능의 일괄 구현이나 커밋 및 푸시 승인이 아니다.

진행 기록의 기준은 프로젝트 Markdown 문서다. PDF는 읽기와 체크용 배포본이며 이후 Markdown 수정이 PDF에 자동 반영되지는 않는다.

## 최신 범위 변경

2026-10-26 사용자 결정으로 벽 매달리기를 이번 프롤로그와 첫 숲 범위에서 제외한다. F 해금은 벽 미끄러짐과 벽차기만 포함한다. 매달리기 전용 입력·상태·애니메이션·VFX·테스트와 필수 지형은 제작하지 않는다. G3의 대안은 벽차기 후 안전한 턱에 착지하는 타이밍 연습으로 제안하며 레벨 제작 전에 검토한다. 후반 별도 획득 방식은 미정이다. 확보한 시간은 벽차기 조작감과 아트 기준 정리에 사용한다.

## 현재 출발점

- 기본 이동, 가속과 감속, 바닥 감지, 가변 점프, 코요테 타임과 버퍼는 기존 검증 기록이 있다.
- 기초 이동 커밋은 `527bd83`이다. 벽 미끄러짐은 `Logs/WallSlideValidation.txt`에 66개 검사 통과 및 원래 씬 복귀가 기록됐다. 사용자는 벽 미끄러짐 동작을 긍정적으로 검토했고 2026-10-27 임시 도구 정리와 최종 보고를 완료했다.
- 벽차기와 이후 전투, 적, 실제 숲, 진행 저장, 프롤로그 및 시각 리소스는 계획 작업이다. 리소스 제작 완료를 가정하지 않는다.

## 매일 진행 순서

- 시작 15분: 오늘 사용 가능한 시간, 전날 미완료와 현재 Git 상태를 확인하고 오늘 반드시 끝낼 결과 하나를 고른다.
- 구현과 디자인: 구현 4~6시간, 시각 작업 2~3시간, 리뷰와 테스트 1~2시간, 마무리 15~30분을 작업량에 맞춰 배분한다.
- 매 기능 종료: 바뀐 파일, 입력부터 결과까지 흐름, 설계 이유, 실제 테스트와 미검증 사항을 확인하고 승인 또는 수정 요청을 기록한다.
- 마무리: 완료, 부분완료, 미검증을 구분한다. 내일 첫 작업, 막힌 이유와 검증 근거를 적는다. 직접 확인하지 않은 항목은 체크하지 않는다.

## 일정이 밀렸을 때

- 이월은 전날 미완료를 다음 날 맨 앞에 놓고 같은 시간만큼 후순위 장식과 추가 변형을 줄이는 방식으로 처리한다. 단순히 다음 날 작업을 계속 쌓지 않는다.
- 필수 진행, 저장, 전투와 조작을 먼저 지킨다. 프롤로그 필수 사건은 짧은 대화와 화면 전환으로 연결하고 배경 종류, 추가 모션과 연출 길이를 줄인다.
- 10월 31일 두 적 전투, 11월 2일 저장과 복귀, 11월 4일 숲 완주, 11월 6일 배포 후보를 중간 마감으로 삼는다.
- 중간 마감이 하루 이상 밀리면 남은 일정을 다시 계산하고 범위 변경을 사용자와 결정한다. 11월 7일과 8일의 검증 시간을 기능 추가로 모두 소진하지 않는다.

## 최종 인수 체크리스트

- [ ] 새 게임에서 마을, 산, 귀환, 사건, 검 획득과 숲 진입이 이어진다.
- [ ] 검 획득 전 공격이 잠기고 벽 능력 해금 전 벽 이동을 사용할 수 없다.
- [ ] 지상과 공중 공격, 후반 점프 캔슬, 피격 취소와 사망 우선 처리가 동작한다.
- [ ] 오소리는 경고 후 공격하고 멧돼지는 벽과 절벽에서 서로 다른 반응을 보인다.
- [ ] 몸체 접촉 피해가 없고 Active 판정과 중복 타격 방지가 동작한다.
- [ ] 회복 중 유효 피격 시 회복과 소비가 모두 없고 최대 소지량이면 아이템이 남는다.
- [ ] 체크포인트는 완전 회복과 적 초기화를 수행하며 아이템 수량을 자동 보충하지 않는다.
- [ ] 사망과 재실행 후 능력, 통로 및 아이템 수량이 보존된다.
- [ ] A에서 B, C, D, E, F, G, H, B를 거쳐 I로 진행하고 숲 완료 화면을 본다.
- [ ] F 이전에는 벽차기 없이 진행하며 B에서 I는 해금 전 우회 불가, 해금 후 통과 가능하다.
- [ ] C와 E는 벽차기 없이 왕복하고 지름길 시간 목표를 측정한다. H에서 B는 안전하게 하강한다.
- [ ] D의 영구 출구가 재잠금되지 않고 전투 중 하부 귀환로가 보이거나 접근 가능하지 않다.
- [ ] 스킵, 사망과 복귀 뒤 입력과 카메라가 정상 복구된다.
- [ ] 캐릭터, 적, 지형, UI와 VFX가 구분되고 공격 예고 및 타격 시점이 일치한다.
- [ ] Windows 빌드에서 새 게임, 이어하기, 종료, 재실행과 전체 완주를 확인했다.
